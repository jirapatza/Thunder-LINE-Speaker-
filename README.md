# Thunder LINE Speaker — อ่านแจ้งเตือน LINE เป็นเสียงบน Android

โหมดหลัก: **LINE แจ้งเตือน → มือถือพูดให้รู้ทันที** จากข้อมูลที่ LINE แสดงในแถบแจ้งเตือนของเครื่อง ไม่ต้องเปลี่ยน Webhook LINE OA, ไม่ต้องติดต่อ Thunder และไม่ต้องเรียก Thunder API เพื่อตรวจสลิปอีกครั้ง

## เสียงที่แอปพูด
- LINE แจ้งว่ามีรูปภาพ: **"มีรูปภาพส่งเข้ามาทาง LINE แล้วเด้อ"**
- LINE แจ้งข้อความที่มีคำว่าสลิป: **"มีสลิปส่งเข้ามาทาง LINE แล้วเด้อ"**
- LINE แสดงยอดเงินในข้อความที่มีบริบทสลิป/ยอด/โอน หรือข้อความจากผู้ส่งชื่อ Thunder: **"มีแจ้งเตือนยอด 180.00 บาทแล้วเด้อ"**
- ข้อความลูกค้า เช่น "สมหญิง ซื้อหวยฮานอย VIP 123": **"สมหญิง ซื้อหวยฮานอย VIP"** (ไม่พูดเลขที่สั่ง)
- มีปุ่มทดลองเสียงและสวิตช์แยกเสียงลูกค้า/เสียงสลิป
- OCR ภาพและภาพบนหน้าจอ LINE เป็นคุณสมบัติเสริม ปิดเป็นค่าเริ่มต้นสำหรับผู้ติดตั้งใหม่

**สำคัญ:** เสียงจากข้อความ LINE เป็นเพียงการบอกว่ามีข้อความแจ้งยอด ไม่ยืนยันยอดเงินจริงหรือผู้ส่งว่าเป็น Thunder ตัวจริง การตรวจสอบยอดทำในระบบเดิมของผู้ใช้ได้ตามปกติ

## ติดตั้งบน vivo V30 Pro / Android
1. ติดตั้ง APK ที่ผ่าน Android CI แล้ว เปิดแอปและกดทดสอบเสียงภาษาไทย
2. กด **อนุญาตอ่านการแจ้งเตือน LINE** แล้วอนุญาต Notification Access ให้ Thunder LINE Speaker จากนั้นกลับมาเปิดแอปเพื่อตรวจคำว่า **สิทธิ์อ่านแจ้งเตือน: อนุญาตแล้ว**
3. เปิดให้ LINE แสดงการแจ้งเตือนและข้อความพรีวิวบนมือถือ และเปิดสวิตช์ที่ต้องการในแอป
4. หากการแจ้งเตือนขึ้นแต่เสียงไม่ดัง ให้ตรวจ TTS ภาษาไทย ระดับเสียง และการจำกัดการทำงานเบื้องหลังของ vivo
5. หากต้องการอ่านยอดจาก **ภาพที่มองเห็น** เอง สามารถเปิด OCR แยกต่างหากและอนุญาตสิทธิ์ Accessibility ได้ ไม่จำเป็นสำหรับการแจ้งเสียงรูปภาพเข้ามา

## ตรวจสอบเสียงขณะทำงานเบื้องหลัง (v0.7)
- หน้าแอปแสดงว่า Notification Listener เชื่อมต่ออยู่ในโปรเซสปัจจุบันหรือไม่ และบันทึกเวลาเชื่อมต่อล่าสุด
- กด **ตรวจสถานะเสียงและแจ้งเตือนล่าสุด** เพื่อดูเวลาที่รับแจ้งเตือน LINE ล่าสุด เวลาที่เครื่องอ่านเสียงเริ่มพูด/พูดจบ และสถานะความผิดพลาดของ TTS
- เก็บเฉพาะสถานะกับเวลาในเครื่อง ไม่เก็บชื่อผู้ส่ง เนื้อความ ยอดเงิน หรือข้อความที่อ่าน
- แก้การเริ่ม TTS แบบอะซิงโครนัส ไม่ให้ callback ที่มาถึงเร็วทำให้คิวเสียงค้าง; หากเครื่องอ่านเสียงขัดข้อง แอปจะลองเริ่มใหม่เมื่อมีข้อความถัดไป
- ข้อความค้างที่ยังไม่ถูกเครื่องอ่านเสียงรับเกิน 2 นาทีจะถูกทิ้ง เพื่อไม่ให้กลับมาพูดข้อความเก่าผิดเวลา
- ใช้ AudioAttributes ประเภทเสียงพูดโดยไม่ขอ Audio Focus จากงานเบื้องหลัง (Android 15+ จำกัดการขอ Audio Focus แบบนี้)
- สถานะ "พูดจบ" มาจาก TTS engine ไม่ใช่การตรวจว่ามีเสียงออกลำโพงจริง
- ระบบยังต้องทดสอบบน vivo V30 Pro โดยเฉพาะเมื่อแอปถูกพักหรือหน้าจอล็อก และไม่รับประกันว่า Android จะปลุกโปรเซสที่ถูกปิดโดยผู้ผลิตอัตโนมัติ

## การกันเสียงซ้ำ
- LINE อาจอัปเดตการแจ้งเตือนเดิมหลายครั้ง แอปจะกันการพูดซ้ำจากแจ้งเตือนเดียวกันในช่วงสั้น ๆ แต่ยังพูดเมื่อพบข้อความใหม่จากห้องเดิม
- หากข้อความใหม่เหมือนกันทุกตัวและ LINE ไม่ส่ง timestamp ของแต่ละข้อความ อาจแยกจากการอัปเดตแจ้งเตือนเดิมไม่ได้
- Debug APK จาก GitHub Actions อาจใช้ลายเซ็นต่างกันในแต่ละรอบ ถ้าติดตั้งทับรุ่นทดสอบเก่าไม่ผ่าน ให้ถอนรุ่นทดสอบเดิมก่อน การถอนอาจลบค่าที่เคยตั้งไว้

## ข้อจำกัด
- แอปอ่านได้เฉพาะข้อมูลที่ LINE ใส่ใน Android notification เท่านั้น เมื่อ LINE แจ้งแค่ "ส่งรูปภาพ" โดยไม่ส่งยอดเงินหรือภาพมา แอปบอกได้แค่ว่ามีรูป ไม่สามารถรู้ยอดเงินในสลิปที่ไม่เปิดเผยได้
- LINE อาจซ่อนข้อความในหน้าจอล็อกหรือรวมข้อความหลายฉบับเป็น notification เดียว ทำให้คำพูดต่างจากข้อความแต่ละฉบับ
- NotificationListenerService ต้องได้รับสิทธิ์จากผู้ใช้ และการเปิดเสียงขณะล็อกหน้าจอขึ้นกับนโยบายประหยัดพลังงานของระบบและ TTS ต้องทดสอบกับเครื่องจริง
- OCR ในเครื่องใช้ ML Kit และไม่ใช่การตรวจสลิปจากธนาคาร

## สิทธิ์และระบบเดิม
- แอปกรองการแจ้งเตือนเฉพาะแพ็กเกจ LINE ทางการ jp.naver.line.android
- การอ่านเสียงจาก LINE notification ทำบน Android โดยตรง ไม่ส่งข้อมูล LINE ที่อ่านไปยัง Cloudflare หรือ Thunder
- โค้ด Firebase/FCM และ Cloudflare รุ่นเดิมยังคงอยู่ใน Repository แต่ **ไม่จำเป็นต่อโหมดอ่านแจ้งเตือน** และหน้าจอใหม่นี้ไม่ทำขั้นตอนจับคู่ Firebase
- ไม่มีการเปลี่ยน Webhook LINE OA, URL ของ Thunder หรือบริการ Bombim00 / Project-1
- แอปยังประกาศ INTERNET permission เนื่องจากโค้ด Firebase รุ่นเดิมที่เก็บไว้ ไม่ควรกล่าวอ้างว่าแอปไม่มีสิทธิ์ใช้อินเทอร์เน็ต
