# Thunder LINE OA Speaker — Android v0.8 (รุ่นทดสอบ)

**ขอบเขตชัดเจน:** อ่านเสียงเฉพาะการแจ้งเตือนจากแอป **LINE Official Account (LINE OA)** บนโทรศัพท์ Android เท่านั้น ไม่อ่านข้อความจาก LINE ส่วนตัว แอปธนาคาร SMS Facebook หรือแอปอื่น

แอป LINE OA ที่รองรับ: `com.linecorp.lineoa` (Google Play: https://play.google.com/store/apps/details?id=com.linecorp.lineoa)

## การทำงาน
- เมื่อ **LINE OA** แสดงข้อความแจ้งเตือน แอปจะใช้เสียงภาษาไทยแจ้งทันทีเมื่อ Android ส่ง notification มาถึง
- ลูกค้าพิมพ์คำสั่งหวย: พูดชื่อผู้ส่งและชื่อหวย **ไม่อ่านเลขที่สั่ง**
- แจ้งรูปภาพหรือสลิป: พูดว่ามีรูปหรือสลิปส่งเข้ามา
- ข้อความที่มีบริบทยอดเงินและมีตัวเลข: พูดว่า "มีแจ้งเตือนยอด ... บาทแล้วเด้อ" ไม่อ้างว่าเงินเข้าแล้ว
- รองรับข้อความใหม่หลายรายการในแจ้งเตือนแบบ MessagingStyle โดยจำกัดย้อนหลังไม่เกิน 2 นาที และไม่อ่านรายการเก่าทั้งห้อง
- กันการส่งแจ้งเตือนซ้ำจาก Android แต่ไม่ทิ้งข้อความใหม่จากห้องเดิม
- ดูเวลาที่ตัวรับแจ้งเตือนเชื่อมต่อ เวลารับแจ้งเตือนล่าสุด และสถานะการพูดได้ โดยไม่บันทึกชื่อผู้ส่งหรือเนื้อหาแชต

## ขอบเขตสิทธิ์ Android
**สำคัญ:** Android ให้สิทธิ์ Notification Access แบบระดับอุปกรณ์ ไม่สามารถเลือกในหน้าขอสิทธิ์ให้เข้าถึงเฉพาะ LINE OA ได้ ตัว NotificationListenerService จึงอาจได้รับ *callback* จากแอปต่าง ๆ แต่โค้ดจะตรวจ package name **ก่อนอ่าน extras / ข้อความ** และข้ามทุกแพ็กเกจที่ไม่ใช่ `com.linecorp.lineoa`

รุ่นนี้ตัดบริการจับภาพหน้าจอ (Accessibility), ตัวรับ Firebase/FCM และระบบ OCR ภาพจาก Android ออกแล้ว รวมถึงไม่มีสิทธิ์อินเทอร์เน็ตที่ประกาศจากแอปโดยตรง โค้ด Cloudflare/Thunder รุ่นเก่าบนเซิร์ฟเวอร์ยังคงอยู่ใน Repository แต่ไม่เกี่ยวกับการทำงานของแอปนี้ ไม่มีการเปลี่ยน LINE OA Webhook หรือเรียก Thunder API ซ้ำ

## การทดสอบบน vivo V30 Pro
1. ต้องมีแอป **LINE Official Account** บนโทรศัพท์และเปิดการแจ้งเตือนของแอปนั้น
2. ติดตั้ง APK สำหรับทดสอบ และเปิด **Thunder LINE OA Speaker**
3. กด **อนุญาตอ่านแจ้งเตือน LINE OA** และอนุญาต Notification Access แล้วกลับมาเปิดแอปตรวจสถานะ
4. กดทดลองเสียงลูกค้า/สลิป/ยอดเงิน จากนั้นให้ LINE OA มีแจ้งเตือนใหม่เข้ามา
5. ทดลองขณะหน้าจอล็อกและปิดหน้าแอป ตรวจดูเวลาที่ได้รับแจ้งเตือนและเวลาที่ TTS เริ่ม/จบจากหน้าสถานะ หาก vivo พักแอปอาจต้องตรวจการตั้งค่าพลังงานของเครื่อง

## ข้อจำกัด
- อ่านได้เฉพาะเนื้อหาที่ LINE OA แสดงใน Android Notification หาก LINE OA ซ่อนข้อความหรือแจ้งแค่ว่า "มีข้อความใหม่" จะไม่เห็นข้อความจริงและไม่สามารถพูดยอดที่ซ่อนอยู่ได้
- เสียงตอนล็อกหน้าจอขึ้นอยู่กับระบบ Android, สิทธิ์ Notification Access, TTS ภาษาไทย, ระดับเสียง และการจัดการเบื้องหลังของ vivo; **ยังไม่ได้ยืนยันด้วยเครื่องจริง**
- สถานะ TTS "พูดจบ" ไม่รับประกันว่าเสียงดังออกลำโพงจริง
- Debug APK สำหรับทดสอบอาจมีลายเซ็นต่างจาก Debug APK ก่อนหน้า; อาจติดตั้งทับไม่ได้
- รุ่นนี้ **ไม่รองรับ** อ่าน LINE ส่วนตัวหรือบริการ LINE OA ที่เปิดผ่านเบราว์เซอร์แทนแอป Android
