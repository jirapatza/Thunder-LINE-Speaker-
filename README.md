# Thunder LINE OA Speaker — Android v0.10 (รุ่นทดสอบ)

**เป้าหมาย:** LINE Official Account (แพ็กเกจ com.linecorp.lineoa) แจ้งว่ามีข้อความหรือรูปสลิป → Android อ่านข้อความหรือ **ยอดในรูปที่เข้าถึงได้** เป็นเสียงภาษาไทย ไม่ตรวจสอบว่ามีเงินเข้าบัญชีจริงและไม่แตะ Webhook / Thunder API เดิม

## อ่านยอดเงินจากรูปได้เมื่อใด
1. **ข้อความ LINE OA ระบุยอดเป็นตัวอักษร:** แอปอ่านยอดจากข้อความแจ้งเตือนได้ตามปกติ
2. **Android แนบภาพจริงมากับ LINE OA notification:** แอปจะ OCR ภาพในเครื่องและพูด "พบยอดในรูปสลิป ... บาทแล้วเด้อ" ถ้าระบุยอดได้
3. **LINE OA แจ้งเพียง "ส่งรูปภาพ":** แอปไม่สามารถเข้าไปอ่านรูปภายในห้องแชตจากข้อความแจ้งเตือนอย่างเดียวได้ จะแจ้งว่ามีรูป แล้วบอกเหตุผลในสถานะ OCR
4. **ทางเลือกเมื่อไม่แนบภาพ:** เปิดรูปสลิปให้เห็นในแอป LINE OA และเปิดสวิตช์ "อ่านยอดจากรูปที่เปิดใน LINE OA" พร้อมอนุญาต Accessibility สำหรับบริการที่ระบุ LINE OA เท่านั้น; ระบบจะ OCR เฉพาะตอน LINE OA อยู่ด้านหน้า
5. **ทางเลือกไม่ใช้ Accessibility:** เปิดรูปแล้วแชร์เป็นไฟล์ภาพให้ Thunder LINE OA Speaker หรือเลือกไฟล์ภาพสลิปในแอป ระบบอ่านข้อความจากไฟล์ที่ผู้ใช้เลือกเอง

**สำคัญ:** การเปิด OCR หน้าจอเป็นตัวเลือกเสริม ค่าเริ่มต้นปิด ระบบ Accessibility มีสิทธิ์ระดับสูงของ Android แม้กำหนดขอบเขตให้รับเหตุการณ์จาก LINE OA เท่านั้น ควรเปิดใช้เมื่อยินยอมและต้องการจริง การจับภาพหน้าจอไม่ทำงานเมื่อหน้าจอล็อกหรือ LINE OA ไม่เปิดอยู่

## สิ่งที่พูด
- มีรูปสลิปและ OCR พบ 180.00: "พบยอดในรูปสลิป 180 บาทแล้วเด้อ"
- รูปไม่แนบมา หรือ OCR หาไม่เจอ: "มีรูปภาพส่งเข้ามาทาง LINE แล้วเด้อ" และแสดงข้อจำกัดในสถานะ OCR
- ข้อความลูกค้า: อ่านชื่อและชื่อหวย ไม่อ่านเลขที่ซื้อ
- แอปไม่รับประกันยอดที่ OCR ได้ การอ่านภาพผิดเป็นไปได้ และเสียง "พบยอด" ไม่ใช่ผลยืนยันโอนเงิน

## เฉพาะ LINE OA ไม่ใช่ทุกแอป
- ตัวอ่านแจ้งเตือนกรองตรงกับแพ็กเกจ com.linecorp.lineoa **ก่อนอ่านเนื้อหา** และไม่อ่านแจ้งเตือนจาก LINE ส่วนตัว ธนาคาร SMS Facebook หรือแอปอื่น
- บริการ OCR หน้าจอที่เปิดเสริมกำหนด android:packageNames="com.linecorp.lineoa" และตรวจแพ็กเกจที่แสดงก่อนจับภาพอีกครั้ง
- ระบบอ่านไฟล์ภาพจะทำเฉพาะไฟล์ที่ผู้ใช้เปิดเลือก/แชร์ให้แอป ไม่สแกนรูปทั้งหมดในเครื่อง
- ไม่ส่งรูป ข้อความ OCR หรือยอดเงินออกไปยังเซิร์ฟเวอร์ และแอป Android ไม่ต้องใช้สิทธิ์อินเทอร์เน็ต
- นโยบายอนุญาต Notification Access ของ Android มีระดับอุปกรณ์; แอปได้รับ callback จากหลายแอปแต่กรองทิ้งทันทีหากไม่ใช่ LINE OA

## ใช้งานบน vivo V30 Pro
1. ติดตั้ง APK v0.10 รุ่นทดสอบ เปิดแอป กดปุ่มทดสอบเสียงภาษาไทย
2. อนุญาต Notification Access ให้ Thunder LINE OA Speaker และตรวจสถานะว่ามีแอป LINE OA บนเครื่อง
3. ให้ LINE OA รับข้อความที่มีสลิป แล้วดูว่าระบบอ่านยอดหรือแจ้งเพียงรูปภาพ
4. หากแจ้งแค่รูปภาพ ให้ลองกดเลือก/แชร์รูปสลิปให้แอป OCR ก่อน (ไม่ต้องเปิด Accessibility)
5. หากต้องการอ่านเมื่อเปิดรูปอยู่ใน LINE OA ให้เปิดตัวเลือก OCR หน้าจอและให้สิทธิ์ Accessibility (บริการ LINE OA เท่านั้น) ทดลองเปิดรูปสลิปบนหน้าจอ
6. เปิดแอปแล้วกดดู **ตรวจสถานะแจ้งเตือนและเสียงล่าสุด** เพื่อดูว่า Android ให้ไฟล์ภาพหรือไม่ และ OCR พบยอดหรือไม่

## ข้อจำกัด
- OCR ใช้ ML Kit แบบ Latin script และตัวเลขในเครื่อง; อักษรไทยบนสลิปอาจรู้จำไม่ครบ จำนวนเงินอาจอ่านคลาดเคลื่อน
- หาก LINE OA ไม่แนบรูปใน Notification และหน้าจอล็อก จะยังไม่สามารถอ่านจำนวนเงินที่อยู่ในรูปได้โดยอัตโนมัติจาก NotificationListenerService เพียงอย่างเดียว
- Android/OEM อาจพักบริการเสียงเบื้องหลัง; ต้องทดสอบบน vivo จริง
- อาจต้องถอน Debug APK รุ่นก่อนก่อนติดตั้งทับ หากลายเซ็นไม่ตรงกัน
- ไม่มีการเปลี่ยน LINE OA Webhook หรือระบบตรวจยอดเงินจริงที่มีอยู่แล้ว
